# ストーリーボード・ナビゲーション設計仕様書

## 1. 目的
`docs/UI-design.png` に基づき、トップページ（Scene 0: Entrance）に各シーンへのクイックアクセスを可能にする「STORYBOARD」ナビゲーションを追加する。

## 2. 設計方針
- **UIのみの変更:** 既存の WebGL 背景演出やアニメーション（`VisualBackground` 等）には一切干渉せず、React コンポーネント層（UI層）のみを修正する。
- **SceneEntrance への統合:** 最初のシーンである `SceneEntrance` 内に、デザイン案に沿ったストーリーボード・セクションを配置する。
- **没入感の維持:** デザイン案のタイポグラフィ、余白、カードスタイルを忠実に再現し、サイト全体の雰囲気に馴染ませる。

## 3. UI 構成
### 3.1. 修正対象: `SceneEntrance.tsx`
現在の表示を `docs/UI-design.png` の文言とスタイルに完全に合わせる。
- **メインタイトル:** "鷹野礼音 OFFICIAL WEBSITE" (大文字、セリフ体、レタースペーシング大)
- **サブタイトル:** "ソフトウェアエンジニア" (中央に配置)
- **デコレーション:** タイトル下の水平線（細い線）
- **ナビゲーションセクション:**
  - タイトル: "STORYBOARD" (セリフ体、さらに広い文字間隔)
  - カード一覧: 以下の 5 つのシーンに対応。
    1. **WELCOME** (Scene 0) - `Welcome`
    2. **PERSONA** (Scene 1) - `Persona & Career`
    3. **RESEARCH** (Scene 2) - `Research`
    4. **ARCHIVE** (Scene 3) - `Archive`
    5. **CONTACT** (Scene 4) - `Contact`
- **フッター:** "SCROLL TO EXPLORE" (またはデザインに合わせた誘導テキスト)

### 3.2. スタイリング (`Scenes.module.css`)
- **カードデザイン:**
  - `docs/UI-design.png` のような縦長のカード形式。
  - 上部にプレースホルダ画像エリア（`rgba(255, 255, 255, 0.05)`）、下部にラベルテキスト。
  - 枠線: `rgba(255, 255, 255, 0.15)`
  - 背景: `rgba(255, 255, 255, 0.03)`
  - 角丸: `4px`
- **タイポグラフィ:**
  - 欧文フォントには `serif` を指定し、デザイン案の洗練された雰囲気を再現する。
  - 日本語名（鷹野 礼音）が必要な場合は、デザイン案の位置（左上等）を確認するが、今回は「3に関しては考慮しない」との指示に基づき、メインタイトルに集中する。

## 4. 機能
- **スムーズスクロール:** カードをクリックすると、該当するシーンのスクロール位置（`window.innerHeight * index`）までスムーズに移動する。
- **レスポンシブ:** モバイル表示時はカードが適切にグリッド状に並ぶ、または縮小されるように調整する。

## 5. 制限事項・禁止事項
- **背景干渉禁止:** `VisualBackground.tsx` やシェーダー関連ファイル（`*.ts`）の変更は厳禁。
- **既存アニメーション保持:** `Framer Motion` による既存のフェードイン等のタイミングは崩さないように配置する。
- **スクロールスナップ:** 既存の `scroll-snap-type` 設定に影響を与えないよう、DOM 構造を慎重に配置する。
