# シーン別タイポグラフィ・視認性向上設計仕様書

## 1. 目的
背景の WebGL アニメーション（星雲、惑星、星々）の動きや色に干渉されず、各シーンのコンテンツを快適に閲覧できるよう、シーンごとに最適化したタイポグラフィ設定を行う。

## 2. 設計方針
- **視認性の最大化:** 全てのテキストに適切なドロップシャドウを適用し、背景との境界を明確にする。
- **背景との調和:** シーンの背景色（紫、青、オレンジ等）に合わせて、フォントの色を微調整する。
- **UI層限定の修正:** 背景演出（WebGL/Shader）には一切触れず、React コンポーネントの CSS/JSX のみを修正する。

## 3. シーン別設定詳細

### Scene 0: Entrance (紫/ピンク系背景)
- **コンセプト:** 幻想的かつ洗練された導入。
- **タイトル:** 純白 (`#FFFFFF`)、強い外光シャドウ (`text-shadow: 0 0 20px rgba(255,255,255,0.3)`)。
- **サブタイトル:** わずかに不透明度を下げた白 (`rgba(255,255,255,0.8)`)。

### Scene 1: Persona (緑/青系背景)
- **コンセプト:** 明るく活動的な印象。
- **カード内テキスト:** 
  - 見出し (`h2`): 純白。
  - 本文: `rgba(255,255,255,0.9)`。
  - シャドウ: 背景の緑/青に埋もれないよう、濃いめの黒シャドウ (`rgba(0,0,0,0.6)`) を適用。

### Scene 2: Research (オレンジ/黄系背景)
- **コンセプト:** エネルギーに満ちた専門性。
- **視認性対策:** オレンジ背景は白文字が最も埋もれやすいため、最も強いテキストシャドウを適用する。
- **フォント:** 見出しのウェイトを上げ、力強さを出す。

### Scene 3: Archive (紫/シアン系背景)
- **コンセプト:** 知的でクールな集積。
- **視認性対策:** 複雑なリスト（論文等）があるため、行間を広げ、各アイテムにわずかな背景色 (`rgba(0,0,0,0.2)`) を追加して読みやすくする。

### Scene 4: Contact (モノクロ系背景)
- **コンセプト:** 落ち着いた結び。
- **視認性対策:** 暗めの背景に合わせ、コントラストを強調。

## 4. 共通の技術的変更
- **Text Shadow の共通定義:** `Scenes.module.css` に視認性向上のための変数または共通クラスを作成。
- **CSS Variables:** シーンごとの色やシャドウを CSS 変数化し、コンポーネント側で切り替えやすくする。

## 5. 制限事項
- `VisualBackground.tsx` および `*Shader.ts` ファイルへの変更は**厳禁**。
- アニメーションのタイミングや WebGL の負荷に影響を与える変更は行わない。
