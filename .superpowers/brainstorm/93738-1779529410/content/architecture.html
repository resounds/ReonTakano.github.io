Architecture: Reactive Cosmic Engine

How the immersive story and interactive background work together

System Overview

Three.js Background (The Universe)

  • Particle System: Reactive nebula using GPU shaders.
  • Planetary Objects: High-quality textured spheres with atmospheric glows.
  • Camera Controller: Smoothly flies through space based on scroll progress.
→

React UI Layer (The Story)

  • Scroll Observer: Maps scroll position to "Story Time".
  • Scene Content: Framer Motion cards that fade/slide in as planets are reached.
  • HUD Elements: Subtle navigation and profile info.
